为本仓库的《小白的股票投资启蒙课》接力一次，只做一批。请求批次：`$1`；省略时使用 `COURSE_STATUS.md` 的当前批次。

1. **恢复，不靠聊天记忆。** 先读根目录 `COURSE_STATUS.md`，再读 `PLAN.md` 中该单元、首页对应提纲和 `preface.html` 的样式。若参数指向已完成或尚未轮到的单元，只报告当前关键词，不重复生产或跳批。若上次中断，核对已有文件和目录链接，列清本次欠哪些课；仅欠发布时直接走收尾。
2. **核对写作者的模型与思考强度。** 模型是 `openai-codex/gpt-6.2-astra`，思考强度是 `xhigh`。使用通用 `task` 子 Agent：先看 `cfg://task/agentModelOverrides` 中 `task` 绑定的角色，以及派发工具列出的该角色对应的模型与强度。若绑定 `@chapter_worker` 且对应 `openai-codex/gpt-6.2-astra:xhigh`，每项只填名字和任务等内容，省略 `agent`、`model` 和 `effort`，让已有配置生效。`chapter_worker` 是模型角色，不是 Agent 名；不要再传 `model` 与已绑定的配置冲突。若无绑定，才在工具允许时显式指定上述模型与强度。不能确认两者时记录具体原因、保留本批关键词，不降档、换模型或由主 Agent 代写。
3. **先给任务单，再并行。** 依据状态表的课号分工，一次派出本批全部独立写作者；不要把一篇课文拆开多人同时改。主 Agent 先约定共同案例、币种、时点、费用假设，以及原始资料（财报批次先固定公司、年度、合并口径和原文）。每位写作者收到课号、题目、学习目标、读者水平、练习和独占输出路径：`lessons/NN.html`，两位十进制编号。子 Agent 只写分到的静态页面，禁止更改共享目录、样式、状态、提交或部署；不单独跑构建或套件。
4. **成稿不是提纲。** 面向初中生，用一个真实问题开课，用一幅解释图或小表讲清关键关系，以一道有答案、有理由的题收尾。遇到公式，先说它算什么，再代数，指出边界；不用公式装饰心理课。费用、史实、规则、引文、财报和实证结论给可核对的原始来源及适用日期；虚构情景和数字明示为假设。不给回本承诺、荐股或对新闻的必涨必跌断言。每节适合一次通勤，不靠堆字数达标。
5. **只有主 Agent 收尾。** 复算关键例题、核对来源和相邻课的口径；补上本批所有已完成页面的目录及前后导航，仅链接实际存在的课。沿用 `reading.css`、`dollar.svg` 和两位课号，路径相对仓库的 Pages 子目录，不引入后端。打开实际页面验证目录→正文→返回、手机排版和图表；按仓库既有方式提交、推送 `main`，确认 Pages 成功部署，抽查在线课程。
6. **落盘才交接。** 及时在 `COURSE_STATUS.md` 记下已产出的课号及待办；新会话须能区别「待统稿」「待发布」「已上线」。全部上线后回写本批结果、更新完成课数、下一批及其关键词，并保存该状态。最后仅交付本批链接、核验结果和一条可复制的 `/stock-next Uxx`；有阻塞就保留本批，不宣称完成，不自动运行下一批。最后一批用「全课完结」代替下一条命令。
